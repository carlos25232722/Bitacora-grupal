Plantilla control de trabajo diario ADSO

  1. Responsabilidad Única (SRP): Cada fila documenta un solo evento, tarea o impedimento indivisible. Si realizó tres actividades en el día, registre tres filas independientes.[cite: 11]
  2. Cero Adjetivos Subjetivos: Prohibido escribir "estuvo chévere", "fue difícil", "avanzamos bien". Redacte únicamente los hechos técnicos verificables.[cite: 11]
  3. Inmutabilidad: Si un registro histórico contiene un error o cambio, no lo borre ni sobrescriba. Cree un nuevo registro con fecha actual indicando: "Corrección/Ajuste al registro ID [X]".[cite: 11]
  4. Impedimentos: Si no presentó dificultades, escriba expresamente: "Sin impedimentos operativos".[cite: 11]

GUÍA DE LLENADO POR COLUMNA

Columna Descripción y Formato Esperado
ID Número consecutivo único para cada actividad o fila (ej. 001, 002).[cite: 11]
Timestamp (YYYY-MM-DD HH:MM) Fecha y hora exacta en la que se registra o ejecuta la actividad (formato AAAA-MM-DD HH:MM).[cite: 11]
Autoría (Responsable) Nombre o iniciales del aprendiz responsable de ejecutar la actividad.[cite: 11]
Objeto Técnico (Actividad y Alcance) Descripción técnica objetiva verificable y concreta de lo ejecutado y su alcance real.[cite: 11]
Evidencia de Ejecución (Entregable / Enlace) URL del commit, enlace al Pull Request, captura de pantalla o documento entregable.[cite: 11]
Impedimentos / Blockers (Qué ejecutó qué falló qué esperaba) Descripción técnica del error o impedimento. Si no hubo problemas escribir: 'Sin impedimentos operativos'.[cite: 11]
Plan de Acción (Mitigación / Próxima Tarea) Acción correctiva tomada, próxima tarea programada o paso para desbloquear la actividad.[cite: 11]
